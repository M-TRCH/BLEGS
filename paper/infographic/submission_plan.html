ส่งบทความ 5 ขั้น Dashboard → New Submission

  1. Start ภาษาไทย · อ่าน Section Policy และ Submission Requirements ก่อนติ๊กทุกข้อ · วาง Comments for the Editor · ยอมรับลิขสิทธิ์
  2. Upload Submission ลากไฟล์ลงพร้อมกัน แล้วเลือกประเภททีละไฟล์ (ตารางขวา)
  3. Enter Metadata คัดลอกจาก ThaiJO_Metadata.txt ทั้งไทยและอังกฤษ · เติมสังกัดและติ๊ก Principal contact · คำสำคัญทีละคำ + Enter
  4. Confirmation Finish Submission → OK — หลังกด OK แก้เองไม่ได้
  5. Next Steps จดเลข ID จากอีเมล Submission Acknowledgement

ตั้งโปรไฟล์ก่อนส่ง 2 ระดับ

  • บัญชีกลาง sso.tci-thaijo.org: ชื่อ นามสกุล สังกัด ทั้งไทยและอังกฤษ · ORCID (ถ้ามี)
  • โปรไฟล์ในเว็บวารสาร: Identity/Contact ลูกโลกเขียว · Working Languages ไทย + English · Roles → Author
  • Notifications: คงค่าเริ่มต้น (ผลพิจารณามาทางอีเมล)

ตรวจก่อนกด Finish

  • ชื่อเรื่องอังกฤษใหม่: …of Mechanical Error for a Quadruped Robot…
  • Comments for the Editor: ตรวจข้อความ [ตรวจว่าเป็นจริง] และย่อหน้าเรื่อง AI
  • อัปโหลดฉบับปิดชื่อเป็น Article Text ไม่ใช่ฉบับมีชื่อ
  • ไม่ส่ง Table5.jpg (ตัดการทดลองนั้นออกแล้ว)

กฎที่พลาดไม่ได้

  • แก้ไขรอบถัดไป: ห้ามกด New Submission (จะได้ ID ใหม่) → Review → Revisions → Upload File
  • ไฟล์แก้ไขต้องปิดชื่อเหมือนเดิม: python paper/anonymize-docx.py
  • ขอแก้ข้อมูลก่อนเข้าสู่ Review: Pre-Review Discussions → Add discussion

ยังต้องดูบนเว็บวารสาร

  • ส่งฉบับปิดชื่อหรือมีชื่อ — ดูใน Step 1 (ค่าเริ่มต้น: ปิดชื่อ)
  • รายการตรวจสอบข้อ 2–3 อ้างแม่แบบภาษาอังกฤษของวารสารอื่น — ต้นฉบับใช้แม่แบบไทยของวารสารนี้
  • ค่าดำเนินการเก็บหลังตอบรับเท่านั้น · ลิขสิทธิ์โอนให้วารสาร
